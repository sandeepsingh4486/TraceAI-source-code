# Judge Scoring Strategy

Use this as your answer if judges ask why the project deserves a high score.

## 1. Problem framing — target 25/25

**Pain:** Engineers and project managers spend hours reading customer emails, ECNs, specifications, and meeting notes, then manually create requirement registers, impact analyses, RAID items, and test plans.

**Specific user:** Embedded/product engineering teams handling requirement changes.

**Measurable baseline:** Use a real manual baseline such as 180 minutes for one medium change package. Measure your own process before the demo if possible.

## 2. AI leverage — target 30/30

The AI is doing semantic work that normal automation cannot reliably do:

- Understand differently worded natural-language requirements
- Split compound statements into atomic requirements
- Connect one requirement to firmware/hardware/interface/test impacts
- Distinguish explicit facts from engineering inference
- Identify missing information and ask targeted clarification questions
- Draft verification cases that trace back to source requirements
- Transform unstructured text into a typed engineering structure

Do **not** pitch it as "a chatbot." Pitch it as a semantic transformation pipeline.

## 3. Practical usefulness — target 20/20

Show an **hours-to-minutes** transformation.

Suggested demo claim:
- Manual baseline: 180 minutes
- AI first draft: measured runtime from the app
- Human review still required
- Value: reduces clerical analysis and lets engineers spend time on decisions

Avoid claiming the AI eliminates engineering review.

## 4. Execution — target 15/15

Demonstrate the complete loop:
1. Input a change request.
2. Generate atomic requirements.
3. Show impact and risks.
4. Open a test case.
5. Show traceability.
6. Download the report.
7. Point out clarification questions.

## 5. Communication — target 10/10

Use one sentence:

**"TraceAI turns an engineering change document into a review-ready requirement, risk, test, and traceability draft in minutes."**

Then tell one story, not ten features.
